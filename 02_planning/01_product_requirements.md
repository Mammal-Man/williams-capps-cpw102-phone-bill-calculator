# Product Requirements

**Team members:** Ty Williams and Garret Capps

Translate the problem statement into requirements. Keep answers brief.

## User and goal

**Who will use this program?**
People with phone plans

**What problem will it help them solve?**
Helping the user monitor their data usage and how much it will cost them
## Requirements

Write each requirement as “The program must…” in your own words. Cover the inputs, processing, and output described in the problem statement. Include the usage categories and input assumptions. Make each statement specific enough to check. Add numbered items as needed.

1. The program must accept a number of gigabytes
2. The program must determine if the number is over or within the users plan, and by how much if they are over
3. The program must tell the user how much their plan costs and if their usage is acceptable, moderate, or high
